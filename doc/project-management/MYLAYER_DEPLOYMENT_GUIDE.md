# Mylayer.org Deployment Guide

This guide will help you deploy your Pessoa project to your Hetzner server with the mylayer.org domain.

## 🚀 Quick Deployment

### 1. Prerequisites
- **Server**: Hetzner server at `91.99.69.115`
- **Domain**: `mylayer.org` pointing to your server
- **SSH Access**: SSH key for `root@91.99.69.115`
- **Docker**: Installed locally for building images

### 2. One-Command Deployment

From your local machine in the project root:

```bash
./deploy_mylayer.sh
```

This will:
- Build the frontend and backend locally
- Transfer images to your server
- Deploy and start all services
- Set up SSL with self-signed certificates

### 3. Access Your Application

After deployment completes:
- **Frontend**: https://mylayer.org or http://91.99.69.115
- **Backend API**: https://mylayer.org/api or http://91.99.69.115:3001
- **Database Admin**: http://91.99.69.115:5050

### 4. Default Login
- **Email**: `admin@mylayer.org`
- **Password**: `mylayer_admin_password_123`

**⚠️ Change this password immediately in production!**

## 🔧 Advanced Options

### Deploy Specific Components
```bash
./deploy_mylayer.sh frontend    # Frontend only
./deploy_mylayer.sh backend     # Backend only
./deploy_mylayer.sh db          # Database only
```

### Deployment Options
```bash
./deploy_mylayer.sh --no-cache     # Force rebuild without cache
./deploy_mylayer.sh --reset-db     # Reset database (destroys data!)
./deploy_mylayer.sh --clean        # Clean up old containers first
```

### Custom Server/Domain
```bash
./deploy_mylayer.sh --server-ip YOUR_IP --domain YOUR_DOMAIN
```

## 🔒 SSL Certificate Setup

### Option 1: Let's Encrypt (Recommended for production)

SSH to your server and run:
```bash
# Install certbot
apt update && apt install certbot

# Generate certificate for mylayer.org
certbot certonly --standalone -d mylayer.org

# Update docker-compose to use Let's Encrypt certificates
# Edit /opt/pessoa/docker-compose.yml:
# In the frontend service, add volume mounts:
# - /etc/letsencrypt/live/mylayer.org/fullchain.pem:/etc/ssl/certs/server.crt:ro
# - /etc/letsencrypt/live/mylayer.org/privkey.pem:/etc/ssl/private/server.key:ro

# Restart frontend container
docker-compose restart frontend
```

### Option 2: Self-Signed (Default)
The deployment script automatically generates self-signed certificates. Users will see a security warning but can proceed safely.

## 🗄️ Database Management

### Backup Database
```bash
# On server
docker exec mylayer_pessoa_db pg_dump -U postgres pessoa_db > backup.sql
```

### Restore Database
```bash
# On server
docker exec -i mylayer_pessoa_db psql -U postgres pessoa_db < backup.sql
```

### Reset Database
```bash
./deploy_mylayer.sh db --reset-db
```

## 📊 Monitoring

### View Logs
```bash
# On server
cd /opt/pessoa
docker-compose logs -f           # All services
docker-compose logs -f backend   # Backend only
docker-compose logs -f frontend  # Frontend only
```

### Check Service Status
```bash
# On server
docker-compose ps
curl -k https://mylayer.org/api/health
```

## 🛠️ Configuration Files

The deployment creates these files:

### Local Files
- `frontend/Dockerfile.prod` - Production frontend Dockerfile
- `frontend/nginx-mylayer.conf` - Custom nginx configuration
- `docker-compose.mylayer.yml` - Production docker-compose
- `deploy_mylayer.sh` - Custom deployment script
- `.env.mylayer` - Environment configuration (generated)

### Server Files (created automatically)
- `/opt/pessoa/.env` - Environment variables
- `/opt/pessoa/docker-compose.yml` - Docker compose configuration
- `/opt/pessoa/deploy_mylayer.sh` - Deployment script

## 🔧 Customization

### Add Environment Variables
Edit `.env.mylayer` (generated by script) or modify the deployment script to add:

## 🆘 Troubleshooting

### Common Issues

1. **SSH Connection Failed**
   ```bash
   # Test SSH connection
   ssh root@91.99.69.115
   ```

2. **Domain Not Resolving**
   ```bash
   # Check DNS
   nslookup mylayer.org
   ```

3. **Services Not Starting**
   ```bash
   # On server, check logs
   docker-compose logs
   ```

4. **SSL Certificate Issues**
   ```bash
   # Check certificate
   openssl x509 -in /etc/ssl/certs/server.crt -text -noout
   ```

### Support Commands

```bash
# Clean restart everything
./deploy_mylayer.sh all --clean --reset-db

# Deploy without rebuilding
ssh root@91.99.69.115 "cd /opt/pessoa && docker-compose up -d"

# Check what's running
ssh root@91.99.69.115 "docker ps"
```
